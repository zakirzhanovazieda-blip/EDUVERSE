# EDUVERSE

Интерактивті 3D білім беру платформасы. Оқушылар виртуалды әлемдерді зерттеп, сабақ материалын оқып, әр бағыт бойынша 10 тест сұрағына жауап береді.

## Жобаны жүктеу

Толық бастапқы код пен құжаттарды [EDUVERSE-source.zip](./EDUVERSE-source.zip) архивінен жүктеп алыңыз. Архивте `src`, `server`, `docs` және іске қосуға қажет конфигурация файлдары бар.

## Іске қосу

```bash
pnpm install
pnpm dev
```

Тесттер: `pnpm test`
